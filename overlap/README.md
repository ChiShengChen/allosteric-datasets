## What is not measured here

Sequence identity. Two different proteins at 90% identity are two different accessions and two different PDB ids, and this file will call them disjoint. A homology-aware version needs an aligner this repository does not depend on; until then, treat every number above as a **lower bound** on how much the sets share.
